# Wana.Work — Marketing Website

The official marketing website for [Wana.Work](https://wanawork-website.vercel.app), an open-source, AI-native Human Capital Management (HCM) platform built for agentic engineering.

## About Wana.Work

Wana.Work empowers organizations to build, customize, and deploy HR systems powered by AI agents — with full control over data, architecture, and infrastructure. No vendor lock-in. No black boxes.

## Pages

- `/` — Homepage: product overview and value proposition
- `/about` — About the team and mission
- `/platform` — Deep-dive into the HCM platform capabilities
- `/solutions` — Industry-specific use cases
- `/open-source` — Open-source philosophy and contribution guide
- `/pricing` — Pricing tiers
- `/contact` — Contact and demo request

## Tech Stack

- Pure HTML/CSS — zero framework overhead, lightning fast
- Deployed on [Vercel](https://vercel.com)

## Local Development

```bash
# Clone the repo
git clone https://github.com/sachinuppal/wanawork-website.git
cd wanawork-website

# Open in browser
open index.html
```

## Deployment

This site auto-deploys to Vercel on every push to `main`.

Live URL: [wanawork-website.vercel.app](https://wanawork-website.vercel.app)
